# Corner matrix — `sg13cmos5l-vco-period-jitter`

Single corner, deliberately: this bench is the **method** record (issue
#518 steps 1-3) — the noise-injection model, its calibration against
`.noise`, and the four validation controls — not the PVT campaign. The
issue's step 6 parks the campaign (nominal + three PVT bundles x two band
codes x two `VCTRL`, plus the row-12 supply-ripple unit) on
2AMLogic/klayout-tools#5772: the pinned klt cannot pin and report a
`trrandom` seed for a batch run, and an unseeded campaign is out of the
question. See `../records/RECORD-001-period-jitter-method.md` "Park".

| Axis | Values | Why |
|---|---|---|
| Process (MOS/RES) | `mos_tt` / `res_typ` only | One operating point is sufficient to validate a method; sweeping before the seed contract exists would burn fleet capacity on numbers that cannot be cited per-seed |
| Temperature | 27 C only | same |
| Band code | `00` (`B0`=`B1`=0 V) | lowest band: slowest ring, longest startup — the conservative case for the 50-crossing skip |
| `VCTRL` | 1.5 V | mid-supply operating point, same one `sg13cmos5l-vco-duty-cycle` uses as its `mos_tt` reference point |
| Supply | 3.3 V fixed | the ratified internal rail (DR-004) |
| Noise seed | 42 (primary + rerun), 43, 44 | the seed-repeat and seed-scatter controls |
| Injected amplitude | `0`, `0.5x`, `1x` (calibrated), `2x` sigma | the noise-off and amplitude-scaling controls |
| `.tran` step | 10p, 5p (max-step axis) | the timestep-convergence control; the noise sample interval `ts`=10p is a source parameter held fixed across both |
| Noise sample interval | 10 ps fixed | source parameter, not tied to the solver step (sinc^2 rolloff at the 10 GHz calibration band edge: -0.14 dB) |

Method units (not corners): the calibration stage (`.op`+`.noise`, 1 A
`.ac`, DC transfer), two calibration transients (seeds 42/43) and one
single-unit **batch** probe attempt whose submit refusals (fleet IAM) and
the silently-ignored `options.transient_noise_seed` are captured in
`seedgap_probe.txt`. Raw results: the CSVs beside this file, generated by
`../testbench/run.sh`.
